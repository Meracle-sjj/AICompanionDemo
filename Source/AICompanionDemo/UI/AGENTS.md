## 世界流转协议（与 GameMode 的契约）

1.1暂停/设置契约：标题页和暂停页的显示设置都由GameMode装配；关闭设置只回到此前标题/暂停输入上下文，不自行恢复世界。ESC/失焦仅提出暂停请求，ResumeRunFromPause须在统一仲裁中保留正在领取的奖励与死亡/终局状态，不由各widget争抢dilation。测试面板收起/展开是内部显示状态，不改变测试账本/输入模式。StartMenu新增OnSettingsClicked→ShowDisplaySettings，构造SetIsFocusable(true)接受关闭设置后的宿主焦点，编辑器DebugActivateMenuAction接受settings，其他封面资源/存活契约保持。PauseMenu/DisplaySettingsMenu的NativeOnKeyDown消费ESC；UE5.6的SButton只处理Accept，ESC可由已焦点按钮沿Slate冒泡到SObjectWidget再调用NativeOnKeyDown；菜单内重复ESC只消费，避免从设置返回后长按继续退出暂停。此为源代码契约，实际窗口键盘/鼠标路径仍需验收。DebugPanel升级列按导演DebugUpgradeCardCount/DebugUpgradeCardLabel实时建树，不再复制旧固定按钮数量/中文名；点击捕获真实Index交给GameMode转发。当前末尾Flip只在导演允许的玩家等级奖励上下文转换，不作为角色技能授予。
标题幕弹入即 SetGlobalTimeDilation(0) 冻结（不刷怪不计时）→ StartRun 解冻=1 开演 → 玩家 OnDeath → Character 布娃娃+禁操作 → ShowDeathScreen 弹死亡屏，1.5s倒地窗后由GameMode::FreezeWorld定格 → 重开=关卡重载全量归位。
